## 1. ‘교육기관명’ 확인 및 입력

교육기관 대표님/원장님에게 직접 입력하도록 하면, 오류/오타/임의 입력된 경우가 정말 많습니다. 따라서 교육기관에서 직접 입력한 명칭조차 그대로 쓰는 것이 아니라 내부 기준에 따라 작성 및 사용해야 합니다.

내부 기준은 다음과 같도록 합니다.

1. **‘사업자등록증’상 상호를 사용합니다.**
2. **사업자등록증 확보 전이라면 ‘네이버 지도’에 등록된 이름을 그대로 사용합니다.**
   - 네이버 지도에 입력된 이름이 교육기관이 등록 시에 가장 많은 고민을 하고 신중하고 정확하게 입력하였을 개연성이 높기 때문입니다.
3. 교육기관이 위 원칙으로 커버할 수 없는 특이한 명칭을 사용중이라면, 메모를 반드시 남깁니다.
   - 예시: 사업자등록증 상 이름과 전혀 다른 이름으로 학원을 운영하고 있는 경우 등
4. 교육기관명에 영어는 가능하면 사용하지 않습니다. 후속 조치를 하는데, 교육기관명으로 검색하는 경우가 많습니다. 영어를 사용하면 이 때 영어로 검색을 해야만 결과가 나오기 때문에, 몹시 혼란스러울 수 있기 때문입니다.
   1. 예시: The상승 → 더상승. 만약 ‘The상승’ 이라고 교육기관명에 적어두면 ‘더상승’으로 검색해도 절대 찾을 수 없음.
   2. 참고: 사업자등록증에는 한국어만 사용 가능합니다. 영어는 불가능한 것은 아니지만, 한국어로 쓰고 영어를 괄호 안에 병기하는 방식으로 쓸 수 있습니다. → 즉, 교육기관명은 상당히 높은 확률로 한국어로된 이름을 사용하고 있을 것이며, 병기하고 있다면 병기한 그대로 사용하면 됩니다.
   3. LEDDI X 레디(LEDDI) SCR 영어학원 제이엠비(JMB) 잉글리시

## 2. ‘주소’ 확인 및 입력

주소는 계약 주체 표시에 중요한 정보이기 때문에, 표준화된 주소를 정확히 입력해야 합니다.

한편 대한민국 정부는 ‘도로명 주소’를 도입했는데, 규칙이 익숙하지 않은 경우가 대부분이라서 그냥 되는대로 입력이 되는 경우도 많습니다. ‘네이버 지도’에 표시하는 주소 조차 그렇습니다.

따라서 다음 규칙을 따릅니다.

- a) ‘사업자등록증’상 주소를 사용합니다. 이 주소가 나라가 정한 기준에 가장 정합한 주소입니다.
- b) ‘사업자등록증’ 확보 전이라면
  - ‘네이버에서 확인한 주소 정보’를 → 행정안전부에서 운영하는 [도로명주소 표준화사이트](https://www.juso.go.kr/openIndexPage.do)(주소정보누리집)에 입력하여 → **나라가 정한 기준에 맞는 주소를 확인하여 입력합니다.**
  - 이 경우 실제 사업자등록증 확보 후 비교해보면 90% 이상 일치합니다.

## 3. ‘내부 표준 명칭’ 확정

‘내부 표준 명칭’ 기준

1. **대괄호** 안에 ‘**교육기관명**’
2. ‘**대표자 이름**’
3. 줄표 **-**
4. 광역시·도 - 시·군·자치구 - 읍·면·동 중 **3개 행정구역까지**
   1. 참고: [https://ko.wikipedia.org/wiki/대한민국의\_행정\_구역](https://ko.wikipedia.org/wiki/대한민국의_행정_구역) → 순서대로 나열하되 a/b/c/d 사이에 한칸씩 띄기.

<Info>
  \[예시\]

  - \[레디어학원\] 김승규 - 서울특별시 마포구 서교동
  - \[디어잉글리시\] 홍길동 - 경기도 고양시 덕양구
</Info>

**\[참고\] ‘내부 표준 명칭’의 사용**

1. ‘클릭업 교육기관DB 태스크명’에 사용되고
2. ‘구글 드라이브 폴더명’으로 쓰며
3. 교육기관 관련 저장하는 세부 파일 명칭으로도 사용합니다.

<Info>
  \[예시\]

  - 사업자등록증\_\[레디어학원\] 김승규 - 서울특별시 마포구
  - 교육기관로고\_\[레디어학원\] 김승규 - 서울특별시 마포구
</Info>

## 참고사항

**1. 교육기관 관련 파일은 모두 구글 드라이브에 보관합니다.**

- 계약서는 물론, 사업자등록증, 통장 사본, 로고 등등 모든 파일은 교육기관별로 생성되어 있는 구글 드라이브 안에 넣어주세요.
- 특히 교육기관 로고는 → 각 교육기관 폴더 안에 보관되어야 합니다.
  - ‘학원 로고 워크북’ 제작은 여기에 있는 로고로 진행됩니다.

**2. 클릭업 ‘기타 참고 URL’에 네이버 지도 링크 넣어두고, 활용하세요!**

- 교육기관은 네이버 지도에 가장 많은 신경을 써서 정보를 입력합니다. 또한 인스타그램/블로그 등 추가 정보도 연결해둡니다. 즉, 네이버 지도는 해당 교육기관에 대한 디테일을 확인하는 가장 좋은 방법입니다. 따라서 **네이버 지도 링크는 반드시 찾아서 입력하는 것**으로 합니다.
- 네이버 지도는 ‘공유’ 버튼에서 단축 URL을 제공합니다. 해당 URL을 입력해둡니다.

**3. ‘구글 드라이브’ 폴더 안에 서류 정리**

- 각 파일명에는 교육기관명 표시되도록
- 각 파일명에 어떤 서류인지 확인 가능하도록 명확히 표시
- 서명 완료된 전자 계약에는 **\_서명완료** 표시
- 계약일 등 날짜가 중요한 경우 날짜까지 표시
