## 내지 PDF

### 인쇄 대상 내지 PDF 전달 받기

### 정해진 위치에 PDF 저장 보관 규칙

- 워크북 최종 작업자가 1번 폴더에 워크북 파일(내지\+표지)을 넣어줍니다.
  - 1번 폴더에 있는 워크북 파일을 2번 폴더로 옮깁니다.

<Frame>
  ![Image](/images/image-58.png)
</Frame>

- 2번 폴더에서 다시 내지와 표지 폴더에 맞게 옮깁니다.
  - 표지는 레디 로고와 학원 로고 디자인이 달라서 이중 체크 필수!
    - 레디 로고 표지는 디자이너가 직접 정해진 폴더에 저장.

<Frame>
  ![Image](/images/image-59.png)
</Frame>

- 내지 PDF 수령 후 아래 작업 진행
  - 뒷1번을 역순으로 볼 수 있게 페이지를 옮기는 작업을 진행.
    - 예시 (레벨 1 기준)
      - 뒤1번을 맨 뒷 번호인 뒤25번으로 옮기기
      - 뒤1번을 뒤24번으로 옮기기
      - 뒤1번을 뒤23번으로 옮기기
      - 계속 반복해서 페이지가 25 → 24 → 23 → …. → 1이 되도록 옮기는 작업 진행.
      <Warning>
        - **주의할 점 : 페이지를 모두 옮기면 메모가 4페이지 연속으로 있는데, 순서가 잘못되지 않도록 이중 체크 하기.**
      </Warning>

<Frame>
  ![Image](/images/image-62.png)
</Frame>

- 페이지 순서를 역순으로 옮긴 후 “뒤”로 저장된 페이지를 180도 뒤집기

# ‘표지 PDF - 학원 로고’ 제작 가이드

## 1. 학원 로고 확인

- 교육기관 DB 구글 드라이브에서 찾아서 → 넣기

<Columns cols={2}>
  <Column>
    <Frame>
      ![Image 65](/images/image-65.png)
    </Frame>
  </Column>
  <Column>
    1. 클릭업에 있는 LEDDI 교육기관 DB 클릭
    2. (오른 쪽 위) Search tasks에서 학원 로고 주문하신 대표님 성함 검색
    3. 클릭업에 적힌 내역과 레디 사이트에 들어온 주문(성함/연락처/주소) 내역을 비교해서 확인 후 동일인인지 확인.
    4. 이상 없으면 연결된 구글 드라이브에 있는 학원 로고 확인. (없을 경우 운영팀이 파일 확인 요청하기.)
  </Column>
</Columns>

- 주문이 들어온 워크북 코드를 확인 후, [\[두잉글 - 제작출고팀\] 디지털인쇄](https://drive.google.com/drive/folders/0AAzz65KTsd59Uk9PVA) 드라이브에서 **“!!\[보관\] 레디 워크북 제작용”** 폴더에 있는 내지와 학원용 로고 파일을 복사
  - “**!\[정규업무 with 열림프린팅\] 제작 요청서 & 전달 PDF**” 폴더 클릭 후, 새 폴더 생성.
  - 새로 생성한 폴더는 정해진 기준(다른 폴더명 참고)으로 폴더명 변경 후, 복사 한 파일을 붙여넣기.

## 2. 표지 PDF 편집

- 동일한 위치에 복사 붙여넣기 가능한지 확인 필요. 경우에 따라서 PSD를 이용하는 것이 더 나은 방법일 수 있음. 승규 대표님과 논의 중
- 로고 넣는 위치 기준
  - 기준 1 - 학원 로고의 가장 윗 부분을 왼쪽 워크북 북코드 높이와 동일하게 맞추기.
  - 기준 2- 학원 로고의 가장 오른쪽 부분을 재단선과 맞추기.

<Frame>
  ![Image](/images/image-67.png)
</Frame>

## 3. 교육기관 확인

- 채널톡을 통해서 직접 전달
- 회신 확인하여 후속 작업 진행

## 4. 발송

- 배송팀에서 도서 수령 후 검수.
  - 인쇄 오류 없는 것 확인 후 발송.

# ‘표지 PDF - 레디 로고’

- (디자이너가 작업 완료한) 인쇄 대상 표지 PDF 정해진 위치에 저장
  - 의뢰 때마다 제작 의뢰 폴더에 잘 옮겨서 사용할 것
  - 2번 폴더(레디 워크북 제작용) → \[표지\] 레디 로고 폴더에 저장.
