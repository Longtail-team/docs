# 인쇄비

- (페이지당): 공급가액 23원. 부가세 포함 25.3원 (참고: 도서는 면세 사업이라 부가세 포함가격을 실제 가격으로 계산해야 함)
  - \[참고\] 부건애드: 페이지당 20원. 부가세 포함 22원.
- 본문 종이 백색모조 100g 기준. 종이가 달라지면 단가 변경될 가능성 있음. 혹은 디지털 인쇄 가능한 종이라면 동일 견적일 수도 있음.

<Info>
  **\[레디워크북 제작 원가\]**

  - 레디워크북은 권당 50-54-58페이지.
  - 제작비는 부가세 포함 2,567원 (58 페이지 기준)으로 생각하면 됩니다!
</Info>

# 제본 비용

- (권당) 무선 제본 : 공급가액 1,000원. 부가세 포함: 1,100원
  - \[참고\] 부건애드: 비용 동일
- 날개 있는 경우 추가 비용 발생.
- 다른 제본 형태 가격은 확인 필요

# 제작 부수에 따른 변경

- 위 견적은 10부 이상 기준.
- 10부 미만은 주문 불가

<Warning>
  2024/06/05 열림씨앤피에서 9부 이하 소량 주문의 제작 단가를 높였음. 최소 10부씩 제작하는 것으로 [결정](https://app.clickup.com/t/86enuggxq). (2024/06/05) [(🔗참고 링크)](https://www.notion.so/doingle/aka-24879594cda6414a91cd164402b45a2c)

- 300부 이상 주문 시 할인 제공 (권당 300부 이상인지, 총합 300부 이상인지 확인 필요)
- 부건애드: 주문은 2부 이상. 무조건 짝수 부수를 맞춰야 함., 500~7000부 이상 추가 할인

# 제작 기간

- 영업일 기준 2박 3일, 성수기는 4박 5일이라고 안내함.
  - 공식 성수기: 3월, 6월, 9월, 12월~2월 \+ 중간고사/기말고사 기간. → 중고등학교 중간고사(4월/10월)와 기말고사(7월/12월) 임을 생각하면 결국 비수기는 5/8/11월 뿐
  - 또한 300부 이상 제작 시에는 시간이 더 소요됨.
  - 따라서 표준 제작 기한은 다음과 같이 설정

<Info>
  디지털 인쇄 제작 소요 시간: N일 의뢰시 → N일 포함 6영업일째 수령, 7영업일째에 발송
</Info>

# 도서 이동/발송 관련

1. to 배송 사무실
   - 이동 비용 청구하지 않음. 단, 우리 요청으로 퀵 발송 등이 발생하는 경우 별도 청구
   - 매일 오전 서울 지역의 경우 직배송. 본인들이 약속을 지키지 못해서 늦어지는 경우 퀵 배송으로 보내기도.
2. to 개별 고객
   - 열림프린팅은 개별 고객 발송 진행하지 않음.
   - 부건애드는 건당 4400원에 진행. 하지만 포장 기자재가 너무 허접해서 이슈가 자주 발생 → 직접하는 것이 나은 것으로 판단됨.

# 가격 예시

- 58 페이지 워크북
  - 제작 사양
    - 사이즈(판형): 210 X 297 (A4) 제본: 무선 제본방향: 세로형좌철 표지 양/단면: 단면인쇄 표지인쇄컬러: 컬러인쇄(4도) 표지용지: 아트지 250g 표지코팅: 유광 코팅 본문 양/단면: 양면인쇄 본문인쇄컬러: 칼라인쇄(4도) 본문종이: 백색모조 100g
  - 인쇄비 58\*25.3 \+ 제본비 1,100 = 2,567 (부가세 포함 가격)
  - **2/4/6/8부 주문시 30% 할증**. 권당 3,337.5원 (최소 주문 2부. 10부 미만은 짝수부 맞춰야 함)
