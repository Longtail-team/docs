## 동영상 설정

<Tip>
  **2024-03-12 내용 추가**

  아래 설정 사항들 중, \[플레이어\] & \[인터랙티브\] 설정은 ‘임베드 사전 설정’으로 적용 가능합니다.

  단, **사전 설정 되어있는 그대로 적용**해야 합니다. (사전 설정을 클릭한 후 세부 항목 설정을 바꾸면 오류인지… 제대로 적용이 되지 않습니다.)

  현재 세팅 되어 있는 사전 설정 목록은 아래와 같습니다.

  \* 새벽달책방, 메타현석, 인티앤, 유로스쿨, 진짜중국어, 낭독스쿨 사전 설정 세팅 방법은 [<u>여기</u>](/74e28f58188d452f9bbe60b1d3be56b4?pvs=25#817dc0d989ec4da0adaa3f3befe5dd6f)를 참고하세요.
</Tip>

- 업로드된 영상을 클릭하면 동영상 설정을 할 수 있습니다.
- 오른쪽에 설정 메뉴들이 있는데, 보통 이 중 \*\*\[프라이버시\], \[플레이어\], \[인터렉티브\]\*\*만 설정합니다.

### 썸네일

- 썸네일은 ‘업로드’ 혹은 ‘동영상에서 선택’이 가능합니다.

<Frame>
  ![Image](/images/image-41.png)

- 동영상에서 선택
  - 영상을 플레이하면서 원하는 화면이 나타났을 때 **일시정지 버튼**을 누르고, 왼쪽 상단의 \*\*‘이 프레임 선택’\*\*을 클릭합니다.
  - 선택한 프레임의 로딩이 완료되면 ‘저장’ 버튼을 클릭합니다.

### 임베드 사전 설정 방법

1. 우측 상단 프로필 이미지 클릭 → 설정 클릭
2. 왼쪽 메뉴 중 동영상 클릭 → 임베드 사전 설정 클릭
3. ‘새 사전 설정 추가’ 클릭

<Frame>
  ![Image](/images/image-47.png)
</Frame>

4. 사전 설정 이름 입력 ➡️ 계속 클릭
