# 개요

인보이스는 “이런 용역을 이렇게 제공했으니, 이 금액을 이 계좌로 보내주세요”라는 문서입니다. 사업자등록이 없어도, 일시적인 프리랜서 용역·강의·컨설팅 등으로 대금을 받기 위해 인보이스(청구서 형식의 문서)를 만들어 상대방에게 보내는 것은 가능합니다.

인보이스를 발행했다고 해서 개인이 자동으로 사업자로 인정되거나, 세금계산서·영수증과 같은 효력이 생기는 것은 아닙니다. 다만 지불하는 우리 입장에서는 법인 사업자이기 때문에 증빙이 필요해서 받아둘 필요가 있습니다.

인보이스 양식은 검색(예: 'Simple Invoice Template')하면 어렵지 않게 찾을 수 있을 겁니다. 아래 내용만 필수적으로 입력해서 PDF 형식으로 전달해 주시면 됩니다.

# **인보이스 필수 포함 내용 / Required Information**

## 1. 개인 정보 (Your Information)

| **항목** | **설명** |
| --- | --- |
| Full Name | 귀하의 영문 성함 (계좌 명의와 일치해야 함) |
| Address | 현재 거주 중인 영문 주소 |
| Contact | 이메일 주소 또는 전화번호 |

## 2. 인보이스 관리 정보 (Invoice Details)

| **항목** | **설명** |
| :-- | :-- |
| Invoice Number | 문서 관리 번호 (예: 20260306-01 등 자유롭게 설정) |
| Date of Issue | 인보이스 발행 날짜 |

## 3. 용역 내용 및 금액 (Description & Amount)

| **항목** | **설명** |
| --- | --- |
| Description of Service | 제공한 서비스의 내용 (예: Translation, Content Creation 등) |
| Total Amount | 최종 수령할 금액 (통화 단위 명시, 예: USD \$500) |

## 4. 수취 은행 정보 (Banking Details for Wire Transfer)

##### 인보이스(Invoice)는 단순한 청구서를 넘어 **'송금 가이드'** 역할까지 합니다. 따라서 인보이스에 이체 받고자 하시는 계좌 정보도 입력도 되어 있어야 합니다.

| **항목** | **설명** |
| :-- | :-- |
| 수취인 이름 (Beneficiary Name) | 영문 풀네임, 계좌 명의와 동일해야 합니다. |
| 수취인 주소 (Beneficiary Address) | 영문 주소·도시·우편번호까지.<br />미국 은행들이 종종 요구하기 때문에 필요합니다. |
| 수취 은행 이름 및 주소<br />(Bank Name & Address) | 상대방이 거래하는<br />은행의 영문 명칭과 해당 지점의 영문 주소입니다. |
| 수취인 계좌번호 | - |
| 라우팅 번호(ABA / Routing Number) | (미국 거주자의 경우만) 미국 내에서<br />특정 은행·지점을 식별하는 9자리 코드 |
| 스위프트 코드 (SWIFT / BIC Code) | <ul><li>전 세계 은행을 식별하기 위한</li><li>8자리 또는 11자리의 영문\+숫자 혼합 코드</li></ul> |
